# 林离曲库 · Olivia Lin Library Tools

把《BSide: Olivia Lin》离线版里**已经下载到本地**的演奏视频，拆成能随便听、随便拷的音乐文件；顺带把你自己电脑上的音乐目录并进同一个播放页。

Windows · Python 3.10+ · ffmpeg · 无第三方依赖。

---

## 这东西为什么存在

《BSide: Olivia Lin》（林离）是米哈游 2026 年 7 月 13 日在 Steam 上架的免费桌面陪伴工具，8 月 27 日发布离线版，8 月 31 日关服下架 —— 从上线到停服不到 50 天。

离线版留住了「听林离演奏」和「动态壁纸」，但曲库只剩下你当时下载到本地的那些。原因很简单：

- 林离的每一首演奏都是**预录 2K 视频**，不随安装包下发，单曲 150–280 MB；
- 点「下载」时，由服务器下发一条**带时效签名的 CDN 链接**（阿里云 Type-A 鉴权，`auth_key=<expire>-<hash>-0-<md5>`）；
- 服务器一关，签名接口消失，CDN 对没有签名的请求一律返回 `401`。

所以**没下载过的曲目无法再取回** —— 这不是客户端功能被阉割，而是签名密钥只存在于服务端。本项目不绕过任何鉴权，也不提供任何在线下载能力，它只做一件事：**把你硬盘上已经有的东西，整理成能听的东西。**

## 它做什么

1. 扫描本地缓存 `%APPDATA%\miHoYo\Olivia-steam\cache\studio\video`
2. 识别 `<曲名>_TOD{1200,1730,2000}_NI_L.mp4`，同一首曲子只取一版
   （实测三个时段版本是同一次演奏 —— 响度分毫不差，只是打光与编码不同）
3. 用 ffmpeg 直接复制 AAC 音频流 → `无损 m4a`（不重编码），内嵌封面与 ID3 标签
4. 另转一份 `mp3 256k`，给车机和老播放器
5. 可选：导入你自己的音乐目录，与林离的曲目分区显示（默认只登记路径，不复制文件）
6. 生成 `曲库.html` —— 一个能筛选、搜索、拖动进度、空格暂停的本地播放页面，
   并且列出**整张曲目表**（包括那些永远拿不到的），让你知道自己缺了什么

## 依赖

- Python 3.10+
- `ffmpeg` 与 `ffprobe`：放进 `PATH`，或设置环境变量 `FFMPEG` 指向 `ffmpeg.exe`
  - Windows 可用 `winget install Gyan.FFmpeg`，或去 [ffmpeg.org](https://ffmpeg.org/download.html) 下静态包

## 用法

```bash
# 默认：提取演奏音轨 + 自动探测音乐目录并导入
python export.py

# 指定要导入的音乐目录
python export.py --import-dir "C:\音乐"

# 只提取，不导入
python export.py --no-import

# 把导入的音乐复制进曲库目录（默认只登记路径，省空间）
python export.py --copy-import

# 换一个演奏视频来源（比如从别的机器拷回来的）
python export.py --src "D:\备份\video"

# 换输出目录 / 顺便留一份原版视频 / 不要 mp3
python export.py --out "D:\Music\林离" --keep-video --no-mp3
```

Windows 上也可以直接双击 `一键更新.bat`。

### 参数

| 参数 | 说明 |
| --- | --- |
| `--src` | 演奏视频目录，默认 `%APPDATA%\miHoYo\Olivia-steam\cache\studio\video` |
| `--out` | 输出目录，默认 `%USERPROFILE%\Music\林离曲库` |
| `--import-dir` | 要导入的本地音乐目录，默认自动探测（`C:\音乐`、`C:\音樂`、`D:\音乐`、`%USERPROFILE%\Music` 等） |
| `--no-import` | 不导入本地音乐 |
| `--copy-import` | 导入时复制文件，而不是只登记路径 |
| `--keep-video` | 把原版 mp4 也复制到 `原版视频/` |
| `--no-mp3` | 只生成无损 m4a |
| `--image-cache` | 封面缓存目录，默认 `%APPDATA%\miHoYo\Olivia-steam\cache\studio\image` |

## 输出结构

```
林离曲库/
├─ 曲库.html            # 播放页面，双击就能用
├─ library.json         # 曲库数据
├─ 无损 m4a/            # AAC 直拷，不重编码
├─ mp3 256k/            # 兼容格式
├─ 封面/                # 从缓存里捞出来的封面
└─ 我的音乐/            # 仅 --copy-import 时存在
```

## 关于 `曲目表.json`

从客户端日志与 CEF 缓存索引里还原出 77 个曲目 key，中文曲名与作曲家是**按曲目推断的**（肖邦的练习曲、李斯特的钟、格里格的夜曲……），难免有错。欢迎 PR 修正。

## 已知限制

- 只能处理本地已有文件，**无法获取未下载的曲目**（原因见上）
- 浏览器放不了的格式（`.ape` / `.wma`）会在页面里提示，需要自己转换
- 导入音乐的标题/艺术家取自文件标签，标签乱了页面也就乱了
- 导入模式只登记绝对路径，原文件移动或删除后链接失效
