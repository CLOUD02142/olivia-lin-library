# 林离 · 书房

**第二代（v2）** —— 给《BSide: Olivia Lin》离线版做的一个本地曲库工具。

把缓存里已经下载好的演奏视频拆成音乐文件，顺便把你自己电脑上的音乐并进同一个界面。
双击启动，浏览器打开就能用：不用命令行、不用联网、不装数据库。

> 第一代是「命令行 + 生成一个静态网页」，能干活但难上手。
> 第二代换成了本地小服务 + 真界面，还加了导入与扫盘。

---

## 第二代改了什么

| | 第一代 | 第二代 |
| --- | --- | --- |
| 上手方式 | 敲 `python export.py` | **双击 `启动.bat`** |
| 界面 | 生成一个静态 HTML，要手动刷新 | 本地服务，边操作边更新 |
| 找缓存 | 自己确认路径 | **自动探测**，找不到会明确告诉你 |
| 导出 | 一次全导，看不到进度 | 列表里标出「可导出」，**支持单曲导出**，有进度条 |
| 导入音乐 | `--import-dir` 参数 | **按钮选文件夹** + **自动扫盘**（快速/全盘） |
| 格式支持 | 相对路径，部分格式放不了 | 服务端流式播放，**支持拖动进度** |
| ffmpeg | 自己装 | 缺了就界面上点一下**自动下载** |

## 快速开始

> **先自查**：打开 `%APPDATA%\miHoYo\Olivia-steam\cache\studio\video\`
> 里面得有 `<曲名>/<曲名>_TOD1200_NI_L.mp4` 这类文件。
> **没有**的话，后面的步骤不用看了 —— 那些曲子已经不可能再下载（见文末）。

1. **拿代码**：右上角 `Code` → `Download ZIP`，解压到任意目录
2. **装 Python 3.10+**：没有的话启动脚本会提示你去官网下（记得勾 `Add Python to PATH`）
3. **双击 `启动.bat`** —— 浏览器自动打开界面，完事

ffmpeg 不用提前装：界面发现你缺它、而缓存里确实有可导出的曲子时，会弹一个「下载 ffmpeg」按钮，点一下自己搞定。

## 界面能干什么

- **自动找到游戏缓存**，把 77 首曲目全列出来，分成三种状态：
  - `已就绪` —— 音轨已经在曲库里，点一下就能听
  - `可导出` —— 视频还在缓存里，点右边「导出」即刻拆成音频
  - `未获取` —— 视频从来没下载过，永久缺失
- **导入音乐文件夹** —— 弹系统对话框选目录，只登记路径不复制文件（省空间）
- **自动扫盘** —— 快速（常见音乐目录）或全盘（所有固定磁盘），会自动过滤掉提示音、闹钟、游戏音效这类几秒钟的短文件
- **播放** —— 拖动进度、调节音量、空格暂停、放完自动下一首；林离的曲目可在 `m4a / mp3` 之间切换
- **搜索与筛选** —— 按曲名/艺术家搜，按古典/原创/弹唱/我的音乐筛

所有数据都留在本机：

| 东西 | 位置 |
| --- | --- |
| 配置 | `%APPDATA%\OliviaLinLibrary\config.json` |
| 标签缓存 | `%APPDATA%\OliviaLinLibrary\probe-cache.json` |
| 导出的音频 | `%USERPROFILE%\Music\林离曲库\` |

服务只监听 `127.0.0.1`，不对外开放；关掉那个黑窗口就停止。

## 命令行

不想开界面也能用（`export.py` 是同一套引擎的薄壳）：

```bash
python export.py --status                 # 只看状态
python export.py                          # 把能导的全导出来
python export.py --no-mp3                 # 只出无损 m4a
python export.py --import-dir "D:\音乐"    # 追加音乐目录
python export.py --auto-scan quick        # 先扫盘再导入
python export.py --out "D:\Music\林离"     # 换输出目录
```

直接启动服务（不经过 bat）：`python app.py`

## 为什么大半曲目是「未获取」

《BSide: Olivia Lin》2026 年 7 月 13 日上架 Steam，8 月 27 日出离线版，**8 月 31 日关服下架**，从上线到结束不到 50 天。

林离的每一首演奏都是**预录 2K 视频**，不随安装包下发，单曲 150–280 MB。点「下载」时由服务器下发一条**带时效签名的 CDN 链接**（阿里云 Type-A 鉴权，`auth_key=<expire>-<hash>-0-<md5>`）；服务器一关，签名接口消失，CDN 对没有签名的请求一律返回 `401`。

**所以没下载过的曲目无法再取回** —— 不是客户端功能被阉割，是签名密钥只存在于服务端。

本项目不绕过任何鉴权，也不提供任何在线下载能力。它只做一件事：**把你硬盘上已经有的东西，整理成能听的东西。**

## 常见问题

**Q：我有 4 首，能补齐剩下的吗？**
不能。那些曲子从来没落到你硬盘上。

**Q：一首曲子有 12:00 / 17:30 / 20:00 三个版本，为什么只导出一份？**
实测是同一次演奏（响度均值 −23.0 dB、峰值 −3.2 dB 完全一致），只是场景打光与编码不同。取 12:00 那版，不重复占地方。

**Q：全盘扫描很慢？**
会遍历所有固定磁盘，只到 7 层目录、最多 2 万个文件，跳过系统目录。一般几分钟。只想听歌的话用「快速」就够。

**Q：扫进来一堆奇怪的东西？**
已经按「时长 ≥ 20 秒」过滤过一遍。如果还有漏网的，点目录标签上的 `×` 移除即可。

**Q：`曲目表.json` 里的中文名准吗？**
77 个曲目 key 是我按曲目推断的（肖邦的练习曲、李斯特的钟、格里格的夜曲……），难免有错，欢迎 PR 修正。

**Q：能放到手机上听吗？**
界面是给电脑用的。要带走就拷 `mp3 256k/` 整个文件夹。
